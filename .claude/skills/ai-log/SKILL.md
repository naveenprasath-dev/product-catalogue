# Log to AI_LOG.md

AI_LOG.md is the raw material for AI_USAGE.md, which the brief requires. Keep entries short and factual.

- **Key prompts / moments:** add a numbered item: what was asked → what the AI proposed → what the
  user decided. Mark the user's own decisions clearly (for example, "(my decision)").
- **Where the AI got something wrong:** what it did, how it was caught, and what was changed. Be honest;
  this section is valuable to the reviewer.
- **Time tracking:** fill in the start and end of each phase (planning, building, testing, reviewing)
  in the table, using real clock times the user gives you. Never invent times.

Write in the user's voice (first person), because the user submits this log. Don't add attribution,
contact details or personal data.
